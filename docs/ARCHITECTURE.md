# Архитектура

## Компоненты

- `MainActivity` — первоначальная настройка, PIN-вход родителя, выбор лимита и приложений, явное согласие на службу специальных возможностей.
- `LimiterAccessibilityService` — получает только события смены активного окна, ведёт секундный heartbeat, учитывает время и создаёт timer/blocker accessibility overlays.
- `ConfigStore` — приватные настройки, PIN-хеш, текущий день, использованное и дополнительное время.
- `PinHasher` — PBKDF2-HMAC-SHA1 с 150 000 итераций, случайной 128-битной солью и сравнением хешей без раннего выхода.
- `AppScope`, `LimitMath`, `DayKey` — чистая логика выбора пакетов, границ/форматирования времени и локального календарного дня.
- `BootReceiver` — один раз после загрузки обновляет дневное состояние. Он не запускает Activity или отдельный сервис.
- `UsbRecoveryReceiver` — принимает только системные USB/media-события, отличает съёмное хранилище от внутреннего и очищает конфигурацию.

## Поток данных

1. Родитель сохраняет PIN, лимит и область контроля.
2. После явного согласия Android открывает системную страницу, где родитель включает accessibility-службу.
3. Служба получает имя пакета при смене окна. Иерархия View и текст окна не запрашиваются.
4. Heartbeat учитывает монотонное `elapsedRealtime` только при активном экране, отсутствии заставки и совпадении пакета с областью контроля.
5. Накопленная дельта сохраняется не реже чем раз в пять секунд и при выключении экрана/остановке службы.
6. Пока остаток положительный, служба показывает маленький таймер. При нуле он заменяется полноэкранным чёрным overlay с локальной PIN-проверкой.
7. «Добавить 15 минут» увеличивает бонус только текущего локального дня. «Отключить полностью» снимает оверлеи и оставляет службу бездействующей до повторного включения в настройках приложения.

## Персистентность

Все значения хранятся в одном приватном `SharedPreferences`. Backup и device transfer выключены. При смене локальной даты использованное и дополнительное время сбрасываются. Для активной сессии используется монотонное время, поэтому изменение настенных часов не создаёт отрицательную дельту; смена календарной даты всё равно зависит от системных даты и часового пояса.

При аварийном отключении питания может потеряться не более последнего интервала записи, обычно до пяти секунд. После перезагрузки Android сам переподключает включённую accessibility-службу; receiver не пытается бесконечно запускать её вручную.

## Границы безопасности

- Это локальный родительский барьер, не системный kiosk/device-owner режим.
- PIN не хранится открытым текстом, но короткий четырёхзначный PIN имеет ограниченную энтропию. PBKDF2 замедляет офлайн-перебор.
- USB — намеренно слабый аварийный ключ по требованию продукта: любое распознанное подключение может удалить PIN и настройки.
- Receiver не экспортирован другим приложениям. Внутреннее/эмулированное хранилище не считается USB-восстановлением.
- Служба не читает дерево окон, не перехватывает ввод, не выполняет сетевые запросы и не блокирует системный boot.
- Ошибка добавления overlay использует ограниченный exponential backoff до 60 секунд, а не плотный retry-loop.

## Совместимость

Используются только платформенные Android API без AndroidX UI-зависимостей. Это уменьшает APK и число конфликтов. OEM может изменить доставку accessibility/USB-событий, порядок окон или политику фоновой работы; поэтому итоговая проверка нужна хотя бы на одной целевой модели каждого производителя.

## Тестирование и выпуск

Unit-тесты проверяют PIN, арифметику лимита, фильтрацию пакетов и USB-политику. Android Lint проверяет manifest/API/TV-ресурсы. `assembleDebug` создаёт устанавливаемый debug APK. Публичный release требует выбранного package ID, закрытого release-keystore и теста на реальном телевизоре; signing material хранится вне репозитория.
