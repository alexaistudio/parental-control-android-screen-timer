# Android Screen Timer 1.5.6

- Пульт: поиск телевизора на первом экране; справка и обслуживание вынесены отдельно.
- Общий лимит и настройки приложения открываются раздельно.
- Для приложения: дневной лимит → «Сохранить дневной лимит»; отдельное поле минут → «Добавить на сегодня» / «Убавить на сегодня».
- На ТВ: нажать на значение минут для точного ввода. Индивидуальные лимиты доступны для установленных приложений без предварительного выбора общего режима. Сохранить настройки кнопкой внизу.
- Варианты значка и списки приложений свёрнуты.
- Исправлено преждевременное завершение ADB-команды по её эху.

USB: существующий сценарий установки через компьютер описан в справке. Прямое USB-подключение телефона к ТВ не добавлено.

Проверки: unit tests, lintDebug, release APK, подписи, соответствие встроенного TV APK. Проверка интерфейса и команд на реальных устройствах не выполнена: ADB-устройства не подключены.
